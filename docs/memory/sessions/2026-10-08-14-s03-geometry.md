## Implémentation

`geometry_trial.py` produit un rapport privé reproductible avec quatre variantes :
repérage brut/normalisé puis géométrie globale/locale. La normalisation avant ORB
reprend `normalized_gray` et conserve tous les contrôles du recalage historique.
`local_registration.py` cherche une translation initiale puis une affine ECC bornée,
sur les cadres imprimés, avec exclusion élargie des zones de réponse. Contrôles des
quatre côtés, déplacement maximal, déformation, couverture et gain mesuré.

Les transformations sont composées avant de projeter la photo source ; masques de
présence, inverse, diamètres source et régions restent disponibles. Refus explicites
sans matrice locale inventée. Le moteur actif n’appelle pas ces modules. Un rejeu
historique intact accompagne chaque expérience. Les annotations ne sont consultées
pour la mesure qu’après le calcul optique ; aucun corrigé dans le lecteur.

## Résultats réels

| Cas | Global brut | Global normalisé | Correction locale |
|---|---|---|---|
| Export annoté, photo monochrome | Refus de distribution/cohérence des repères | Alignement accepté par les contrôles historiques | Trois grilles refusées : cadre imprimé insuffisant après exclusion |
| Ancien diagnostic monochrome | Même refus global | Alignement accepté | Même limite locale |
| Ancien diagnostic couleur basse résolution | Alignement accepté | Alignement accepté | Même limite locale |

Sur les 40 cadres humains de l’export, le repérage global normalisé place les centres
de **tous les choix dans 40/40 cadres**. Distance médiane entre centre des choix et centre
du cadre : **1,148 pixel source**. Ce n’est ni une erreur mesurée sur des centres humains
exactement annotés, ni un taux de lecture, ni une validation des contours des cases.
Une seule acquisition annotée, déjà utilisée pour développer, aucune généralisation.

Le gain observé provient du prétraitement global, pas de la correction locale. Le masque
conservateur retire notamment presque tout le bord inférieur des grilles serrées NITE.
Ce cas reste une limite à résoudre ; aucun assouplissement opportuniste du refus. Sur
synthétique avec cadres suffisamment espacés, les déplacements connus sont corrigés,
y compris questions verticales à cinq choix. Un saut d’une question est refusé.

Rapports privés : `artifacts/private/baselines/s03-annotated-v2/`, `s03-photo-v1/` et
`s03-monochrome-v1/`. `summary.md`, `review.html`, régions/crops et `report.json` avec
empreintes. L’ancien essai exploratoire v1 est conservé ; v2 correspond au code final.

marques à moins de 0,1 pixel sur les points projetés, identité sans faux gain, refus de

conservé après échec global. Le test compare les points projetés, pas les coefficients
